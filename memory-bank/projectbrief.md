# Project Brief - YTDx (YouTube Downloader)

## Overview
YTDx is a modern, feature-rich desktop YouTube downloader application built with Python and PyQt6. It provides a graphical user interface for downloading videos, audio (MP3/M4A), playlists, and video thumbnails with rich customization options and multi-language support.

## Core Features & Scope
- **Video & Audio Downloads**: Single video download in various resolutions (up to 4K/1080p), audio extraction with metadata tagging (mutagen).
- **Playlist & Batch Downloads**: Fetching and downloading full YouTube playlists.
- **Modern PyQt6 GUI**: Fusion style with dark/light themes and custom UI components.
- **FFmpeg Integration**: Automatic FFmpeg detection for high-quality audio conversion and stream merging.
- **Internationalization (i18n)**: Multi-language support (Turkish, English, etc.).
- **Download Management**: Progress tracking, speed calculation, queue handling, and customizable download directories.
